# 03 — Screenshots

Save your own screenshots here after completing the lab. This folder intentionally contains no fabricated evidence.

## Suggested filenames
1. `01-interface-addresses.png` — output of `ip -br address`
2. `02-http-capture-running.png` — tcpdump listening for HTTP capture
3. `03-http-display-filter.png` — Wireshark with `http` filter
4. `04-http-post-fields-redacted.png` — HTTP POST/form fields with all sensitive values hidden
5. `05-https-capture-running.png` — tcpdump listening for HTTPS capture
6. `06-https-port443-filter.png` — Wireshark with `tcp.port == 443`
7. `07-tls-application-data.png` — TLS/Application Data packet details
8. `08-capture-summary.png` — optional summary of packet counts

## Screenshot checklist
- [ ] Screenshots are readable and relevant
- [ ] Credentials, cookies, tokens, and personal details are blurred or cropped
- [ ] Captions explain what each screenshot demonstrates
- [ ] Evidence is genuine and comes from your own lab session

Use PNG or JPG. Do not use screenshots that expose real credentials.
